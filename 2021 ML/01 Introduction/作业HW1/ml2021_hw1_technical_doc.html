00

任务概览

给定美国各州连续三天的 COVID-19 流行病学数据，预测第四天的新增确诊人数。这是一个回归任务——输入是数值向量，输出是一个连续的实数。

端到端 Pipeline — 从 CSV 到预测结果
什么是回归？
与分类（输出类别标签）不同，回归的输出是连续数值。本任务输入 93 个特征，输出"明天的确诊人数"——可能是 1234.5 这样的小数，模型不需要判断类别，只需尽量逼近真实数字。

概念解释

什么是 One-hot 编码？

有 40 个州，如果用数字 1–40 代表各州，模型会误以为"州40"比"州1"大 40 倍——这没有意义。One-hot 用一个长度为 40 的向量，当前州对应位置填 1，其余全 0，彻底消除这种虚假的数量关系。

训练 / 验证集划分

用固定索引规则划分，不随机打乱：索引 % 10 == 0 的样本进验证集，其余进训练集：

9:1 划分示意 — 每10条取第0条为验证集

特征标准化（Z-score）

时间序列特征（第41列起）的数量级差异巨大——"检测人数"可能是万级，"阳性率"是小数。不标准化会导致梯度方向偏斜、收敛慢。Z-score 将每个特征拉到均值=0、标准差=1：

x_new = (x − mean) / std
标准化前后对比 — 量纲统一后梯度下降更稳
为什么 one-hot 列不标准化？
One-hot 的值只有 0 或 1，已经处于相同量级，标准化反而会破坏这种离散性质，让 0/1 变成非整数，增加不必要的噪声。
02

Dataset 与 DataLoader

Dataset 像一个"数据仓库"，知道第 i 条数据在哪、长什么样；DataLoader 像"配货员"，每次取出一批送给模型：

Dataset 三个必须方法 + DataLoader 协作关系
为什么需要 DataLoader？
将 2430 条全部一次输入显存不够，梯度估计也偏（方差大）。DataLoader 每次取 270 条，模型频繁更新参数（每批1次），2430 ÷ 270 = 9步完成1个epoch，内存可控，收敛更快。

激活函数 ReLU 的意义

概念解释

为什么需要激活函数？

两个线性变换叠加 W₂(W₁x+b₁)+b₂，展开后仍然是 W·x + b，与一层没有本质区别。激活函数引入非线性——ReLU 对负值输出 0，正值原样输出——打破线性限制，让深层网络能表达复杂的非线性函数。

损失函数：均方误差 MSE

MSE 计算预测值与真实值的平均平方误差，作为衡量模型好坏的数值信号：

MSE = (1/N) × Σᵢ (ŷᵢ − yᵢ)²
MSE 直觉 — 平方放大大误差，激励模型精确预测

训练集 loss 可以无限下降，但验证集 loss 会在某个点回升——那是过拟合的开始，模型开始"死记"训练数据。早停在验证集 200 轮未提升时叫停：

05

超参数配置

所有可调参数集中在 config 字典——改这里就能切换实验，无需改动训练代码：

Python
config = {
    'n_epochs': 3000,       # 最多训练 3000 轮（早停可提前结束）
    'batch_size': 270,     # 每批 270 条（= 验证集大小）
    'optimizer': 'SGD',    # 动态加载：getattr(torch.optim, 'SGD')
    'optim_hparas': {
        'lr': 0.001,           # 学习率：每次参数更新的步长
        'momentum': 0.9,       # 动量：积累历史梯度方向
    },
    'early_stop': 200,     # 验证集连续 200 轮无提升则停
    'save_path': 'models/model.pth',
}
参数默认值直觉解释
batch_size270批越大梯度越稳、内存越大；批越小更新越频繁但噪声更多
lr0.001太大在最优点附近震荡，太小收敛极慢——通常 0.001 是安全起点
momentum0.9记住90%历史梯度方向，像"滚球"越过小坑，加速收敛
early_stop200耐心值越大越可能找到更优解，但也越耗时
概念解释

Momentum（动量）是什么？

普通 SGD 每步都只看当前梯度，方向容易震荡。Momentum 像一个有惯性的球——记住上一步的运动方向，不会因为单次梯度变化就急转弯。公式 v = 0.9×v + ∇W，W = W - lr×v：速度 v 不断积累，平坦方向加速，震荡方向互相抵消。

07

性能提升建议

按影响由大到小，建议依次尝试：

  • 特征
    特征选择：完成 target_only=True 分支，只保留 40 个州指标 + 2 个 tested_positive 特征（索引 57 和 75）。减少噪声输入，模型更专注于强预测特征。
  • 训练
    切换 Adam 优化器：将 config['optimizer'] 改为 'Adam'，删去 momentum。Adam 为每个参数自适应调整学习率，通常比 SGD 收敛快 2–5 倍。
  • 模型
    加深网络：改为三层或更多（如 93→256→128→1），加入 BatchNorm1d（稳定每层输入分布）和 Dropout(p=0.2)（训练时随机丢弃，防过拟合）。
  • 正则
    L2 正则化：在优化器加 weight_decay=1e-5，惩罚过大权重，减少过拟合，提升泛化。
  • 数据
    正确的标准化：用训练集的 mean/std 统一标准化验证集和测试集，避免测试集信息泄露到预处理流程。
